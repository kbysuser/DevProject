問題 1: SYN Flood 検知
q_synflood.pcap を解析して、攻撃元 IP アドレスを特定してください。

説明
この PCAP には、Web サーバ 10.0.0.10:80 への通信が記録されています。
正常なクライアントからの TCP 3-way handshake と HTTP GET も混在していますが、攻撃者は大量の SYN パケットを送信してサーバを狙っています。

目的
攻撃者の IP アドレスを特定すること
ヒント
Wireshark でフィルタ: tcp.flags.syn==1 && tcp.flags.ack==0
ip.src ごとにパケット数を確認
Statistics > Conversations の TCP タブも有効
想定される答え
攻撃元 IP: 203.0.113.66
