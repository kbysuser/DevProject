SYN フラッド検出

ファイル: q_synflood.pcap
説明: Web サーバ 10.0.0.10:80 へ大量の SYN パケットだけが送られており、正常クライアントの 3-way handshake と混ざっています。
目的: SYN フラッドの攻撃元 IP を特定する。
ヒント: Wireshark で表示フィルタ tcp.flags.syn == 1 && tcp.flags.ack == 0 を使い、Statistics > Conversations の TCP タブや ip.src ごとのパケット数で上位を確認する。正常通信は SYN→SYN/ACK→ACK→GET を伴う点を比較する。
想定解: 203.0.113.66
難易度 / 学び: 基礎（TCPフラグの意味、SYNフラッドの検知手法、会話統計の使い方）
